# 👥 Agenda de Contatos — KeyPasso

## 📌 Sobre o projeto
A Agenda de Contatos é um dos módulos do KeyPasso, desenvolvido como parte do projeto final da disciplina de Programação Orientada a Objetos (POO).

O sistema tem como objetivo permitir o cadastro e o gerenciamento de contatos de forma organizada.

## 🎯 Objetivo
Desenvolver uma agenda de contatos utilizando Java, Programação Orientada a Objetos, Swing e MySQL, aplicando operações de cadastro, consulta, alteração e exclusão de dados.

## 🖥️ Funcionalidades
- Cadastro de contatos;
- Listagem e busca de contatos;
- Atualização de contatos;
- Exclusão de contatos;
- Armazenamento dos dados em MySQL;
- Interface gráfica utilizando Java Swing.

## 🛠️ Tecnologias
- Java
- Java Swing
- Programação Orientada a Objetos
- MySQL
- JDBC
- Git
- GitHub
